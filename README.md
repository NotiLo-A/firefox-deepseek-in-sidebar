# <img src="src/icons/icon.svg" width="64" height="64" /> Kimi in Sidebar

This project is a fork of the [DeepSeek in Sidebar extension](https://github.com/NotiLo-A/firefox-deepseek-in-sidebar). It is a Firefox extension to display Kimi within the Firefox sidebar.

It contains support for shortcut functionality from the original source code, which you can customize in the options menu. The extension icon will also toggle between light mode and dark mode

Nothing else in fork has been modified except for showing Kimi in the sidebar instead of DeepSeek.

[![Get the Addon](https://raw.githubusercontent.com/semanticdata/text-revealer-firefox-extension/master/firefox.png)](https://addons.mozilla.org/en-US/firefox/addon/deepseek-in-sidebar/)
